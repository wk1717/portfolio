CSS (Children Safety System)

시기 2023분야 IoT규모 6명수상 어드벤처디자인 교내 장려상

개요

  • 부엌에 들어간 아이의 사고(전자레인지 화재 등)를 막는 IoT 안전 관리 시스템
  • 하드웨어 센서 제어와 모바일 알림을 결합
  • 교내 아이디어 경진대회 장려상 수상

회로

기술 스택

ArduinoRFID초음파 센서온도 센서불꽃 감지 센서PushingboxPushbullet

작동 원리

출입

  • 보호자가 부엌을 나갈 때 RFID 카드 태그
  • RFID 인식 시 아이 보호 모드(센서 감지) 시작

센서

  • 초음파 센서: 보호자 접근이 감지되면 감지 동작 중지
  • 온도 센서: 일정 온도 이상이면 보호자에게 알림
  • 불꽃 감지 센서: 불꽃 감지 시 보호자에게 알림

알림

  • 아두이노 HTTP 통신으로 신호 전송
  • Pushingbox 시나리오 실행 → 연동된 PC의 Pushbullet으로 알림
  • PC와 연결된 휴대폰에 알림 전달
